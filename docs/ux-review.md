# Gridlet 0.2.0 — Native UI pass (UX audit)

## Screens and states

| Surface | States | Notes |
|--------|--------|--------|
| Floating grid panel | Idle, hover, drag selection, live target, no target, resize error | 320×380 fixed; grid is hero; footer shows hint or % size |
| Gridlet Settings | Single pane | Open Gridlet hotkey recorder, grid steppers, preview, close-after-resize, login, AX blurb |
| Accessibility gate | Permission missing | Native titled window (no nested panel chrome); Open Accessibility Settings + Quit |
| Menu bar | Click → status menu | Ready / AX / shortcut status; Show Grid, Settings…, Quit |

## Primary journey

| Step | Action | Result |
|------|--------|--------|
| 1 | User-defined global hotkey (default ⌃⌥Space) or menu **Show Grid** | Panel opens on active display(s) |
| 2 | Mouse down / drag on tiles (gaps included) | Accent selection + optional preview overlay |
| 3 | Mouse up | Target window resized; panel closes unless “Close after resizing” off |
| Esc / click outside / ✕ | Dismiss | No resize |
| ⚙ | Settings | Single settings window |
| AX denied | Permission sheet | Explains requirement; no auto-grant |

## Design grammar

- **Chrome:** `PanelChromeView` — popover material on the **floating grid only**; settings and permission use plain `windowBackgroundColor` inside standard titled windows.
- **Spacing:** ~17pt padding; header ~32pt; footer ~24pt.
- **Grid:** 3.5pt gaps, 5pt tile radius, adaptive label-tint idle fill + subtle tile edge, accent selection + outline.
- **Type:** System 13pt semibold header title; 11pt secondary footer/hints.
- **Header target row:** 22×22 app icon + 6pt gap + title as one `TargetAppHeaderView`, centered between ✕ and ⚙ (truncates inside close/settings margins; panel stays 320×380).
- **Appearance:** Light/dark via system colors only (no hardcoded dark surfaces).

## Removed (intentional)

- Three-tab Preferences, preset list/editor, per-preset local shortcuts.
- Keyboard grid controls (+/−, Option subdivide, Shift invert) while panel open.
- Preset-related tests (`GridPreset`, `PresetLocalShortcutMerge`, preset resolution tests) — see test count vs 0.1.1.

## Retained

- Configurable **global** open shortcut with layout-aware labels (TIS / UCKeyTranslate), transactional registration, recorder lifecycle tests.
- Geometry, AX/window target, input routing (`sendEvent`) regression tests.
